# Logos

| File | Use |
|---|---|
| `discord-avatar.png` | Bot / server avatar with the "MK8DX TIMES" wordmark (1024×1024) |
| `discord-avatar-icon.png` | Icon-only version, more readable at small sizes (1024×1024) |
| `logo.svg`, `logo-icon.svg` | Editable sources (the wordmark uses the Russo One font from `node_modules/@fontsource/russo-one`) |

Transparent background. Original artwork: stopwatch + checkered flag. No Nintendo assets are used.

## Instagram story

`instagram/story.png` (1080×1920) is rendered from `instagram/story.html`. To change the text, edit the HTML and
take a 1080×1920 screenshot of it (any browser at that size). The top and bottom 230 px are kept free for Instagram's interface.
